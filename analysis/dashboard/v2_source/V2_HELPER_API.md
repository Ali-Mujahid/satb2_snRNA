# V2 display helper contract

Load `v2_features.js` as a local classic script before `app.js`. It exposes `window.SATB2_V2`; there are no dependencies, network calls, counts extraction or statistical fits.

* `clamp(value,min,max,fallback=min)`: finite number clamp for display controls. Numeric strings are not silently treated as observations.
* `range(values,override?)`: finite observed range, excluding null/NaN/infinity. An explicit `[min,max]` or `{min,max}` display override requires min < max. Returns null if nothing is observed and no valid explicit override exists. Source values are never changed.
* `dotGeometry({fraction,z,metric,value?,negativeZ=true,maxArea=100,negativeArea=.25,negativeAlpha=.18,alpha=.9,glyphScale=1})`: returns `{value,fraction,negative,area,radius,alpha,fraction_valid}`. Fractions must be finite within [0,1]; missing/invalid fraction yields null area/radius. `metric='scaled_expression_z'` uses z unless value is provided; fraction_detected uses fraction. Other metrics should pass explicit value. GlyphScale multiplies radius, so area is multiplied by scale². Negative attenuation applies only to negative z with enabled policy. Zero fractions/counts stay zero; missing values stay null.
* `transformCoordinates(nuclei,basis='harmony',spacing=1)`: returns a **new array** of `{x,y,cluster_id,nucleus_id,source_x,source_y,spacing,display_only,source_coordinates_modified:false}`. Reads x_harmony/y_harmony or x_unintegrated/y_unintegrated. Spacing clamps to [0.25,2.5]. At1 the original coordinates are exact. Otherwise each original cluster centroid is displaced by `(spacing-1)*(centroid-globalCentroid)`, retaining within-cluster offsets. Global centroid is nucleus-weighted over finite source coordinates. Invalid pairs remain null. Root should enable this only for IN, default1, and disclose changed display distances. No embedding/source coordinate changes occur.
* `quantile(sorted,p)`: linear interpolation at `(n-1)*p`, assuming finite sorted values. Empty returns null.
* `boxStats(values)`: finite values only; returns `{n,q1,median,q3,iqr,lowerFence,upperFence,whiskerLow,whiskerHigh,outliers,minimum,maximum,quantile_definition}`. Fences are q1−1.5IQR/q3+1.5IQR; whiskers are most extreme observed values inside fences. A single observation has all quartiles/whiskers equal. This is descriptive display, with no test.
* `mousePoints(rows,{countKey='count',factorKey='size_factor',sampleKey='sample',conditionKey='condition'}?)`: one output per existing mouse row, preserving original fields and adding `{source_count,recorded_size_factor,normalized_value,value,missing_reason,normalization,biological_unit,statistical_test_performed:false}`. Missing/negative count or absent/nonpositive SF produces null, never invented zero. Count0 with recorded SF>0 produces0. Duplicate/missing mouse identities throw. Excluded mice remain present; unavailable recorded SF remains unavailable. Root binds rows to exact existing population/count branch/endpoint, not arbitrary edited selections.
* `mouseRows(countPayload,fit,geneIndex,samples=[])`: turns a selected global stable-gene index from the existing mouse count shard into12 source rows for mousePoints. Requires matching sample axes and all12 SF/eligibility/nucleus audit arrays; validates safe nonnegative integer counts. Only declared EXPLICIT_ALL_ZERO omitted rows become zeros. Unknown gene index or undeclared missing counts throws. Conditions come from supplied sample metadata, with no genotype inference from ID. The selected fit.id and countsSHA remain on every row.
* `labelSuggestions(clusterRow,additionalSourceLabels?)`: returns deduplicated **provisional display candidates** from existing reviewed/identity/program/reference fields. Every candidate preserves source key/confidence and states physical_layer_assignment=UNDETERMINED/scientific_annotation_modified=false. It does not infer or apply a new biological annotation.
* `markerLayout(nGenes,nRows,{labelWidth=260,columnWidth=18,rowHeight=26,minWidth=700}?)`: returns display width/height/row-column dimensions and pagination capacities [60,90,120,180]. Sets horizontal-scroll guidance above30 columns. Exact numeric gene values are unchanged; wide plots should render/scroll at returned intrinsic width rather than squeeze60+ labels into a narrow card.

Root owns the app/HTML/CSS integration, source-fit/marker provenance, member masks and all UI state. Helper metadata is a display audit, not evidence of fitted UMAP distances, molecular identity or new gene-level inference.
