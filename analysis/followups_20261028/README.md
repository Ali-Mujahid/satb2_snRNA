# Four separate SATB2 follow-ups — 28 October 2026

The native analyses use the existing 12 independent mice and preserve earlier analyses and original DESeq2 fits. Actual run source, configurations, selected input matrices, complete native models, results and reviews are distributed in six separate release archives; the additional flat portable ZIP opens directly without Python/R. The copied presentation/publication source here packages reviewed existing files and never fits or rescales scientific results.

- scCODA: one initial family and one globally specified stricter numerical check. Four strict models pass sampling diagnostics; twelve remain inconclusive. Two mixed excitatory category associations are relative to flagged reference clusters and do not establish absolute cell expansion. Native Bayesian FDR and PIP differ from gene-DE statistics.
- CellChat: both ends are original matching-endpoint Seurat DESeq2 DEGs, including every required complex subunit. The three requested direction views preserve signed components and independent-mouse score comparisons. Three primary full-cohort associations have lower cKO scores; none qualifies in the primary shared-partition comparison. These are exploratory, same-data selected RNA associations. Readable-layout figures are separate exact-value derivatives; originals are retained.
- Monocle3: CA1 programs and three separate inhibitory scopes produce four unrooted expression-state graphs and associated gene modules. Arbitrary-root distance is not established biological pseudotime or genotype differential expression.
- scVelo: input blocked, not executed. Genuine separate spliced/unspliced measurements and verified complete read-level inputs/access are required.

Molecular CA1 programs do not establish anatomical layers. Genotype partly overlaps sequencing partition. The tools and sampler checks reuse the same mice; they are not independent biological replications. The full native reviews explain coverage, reference dependence, uncertain identities and method-specific inference.

The frozen source-validation records describe the pre-build source review at their recorded times. Actual portable and online delivery receipts establish later package identity. Do not change archived scientific configuration files in place. For restoration on another system, use a fresh destination and the supplied extraction helper; edit copies of original-path configurations only for a separately planned reanalysis. The native environment locks identify package versions and upstream source distributions rather than promising a universal installer.
