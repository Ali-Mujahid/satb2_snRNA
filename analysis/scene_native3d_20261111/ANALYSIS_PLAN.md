# Native 3D SCENE: plan

Goal: recreate the user-supplied animation's real model-training geometry using the same Seurat-defined P60 CA1/ProS nuclei, rather than the earlier 3D PCA of a 16-dimensional final model. Input is the previously validated original-full raw-count H5AD, 27,703 nuclei, 2,518 selected genes, 6 WT and 6 cKO mice, with original Seurat clusters and superficial/deep-associated programs. The mouse is the independent experimental unit; this is a descriptive embedding, not genotype DE.

Method: SCENE 0.1.2, native latent dimension 3, ZIP likelihood, 1,200 epochs, seed 42, 512-cell blocks, low-rank mouse batch, same original package optimizer/loss and count input. 10% of nonzero entries held out under the package's default flipped validation; distinguish actual validation metrics from biological quality. A frozen copy of SCENE's native trainer is instrumented in memory to record actual coordinates at initialization, epoch 1 and every five epochs; no installation or mutation of the original package. Original 16D model, labels, fits and files remain untouched. Separate fresh run directory. Training frames show actual checkpoints, repeated for display, not inferred biological trajectories. RNA counts/cell-gene edges reflect actual positive raw UMI entries; no ligand-receptor inference.

Evidence gates: exact input/trainer SHA256, dimensions, 12-mouse labels, integer counts; complete 242 checkpoint files of expected finite dimensions; final model and loss/validation history; source count verification for 96-cell displayed heatmap and highlighted nonzero edges; actual training and video log; inspect frames for legible labels and truthful captions. Compare embeddings descriptively; no promise of matching another dataset, no false biological separation or anatomical assignment. Sample batch adjustment could absorb genotype-associated variation. Results require scientific review and independent experimental validation.
