# Grm7 twelve-mouse transcript-feature evidence

This additive workflow implements the user's requested BAM/GTF Grm7 isoform, exon and splice-junction analysis in frozen Seurat CA1 layers and inhibitory neurons. It does not refit or overwrite existing analyses. Entry point: `Snakefile`; supply JSON `--configfile` with absolute roster, original gene table, local Python, result directory and `bound_config` (the JSON file itself). Snakemake is the existing 9.27.0 local controller. The counter uses Python standard library only; task requirements are Python 3.12 and SSH locally, authenticated LiSC access, remote Python 3.9 and existing SAMtools 1.22.1, matching GTF/reference FASTA plus FAI, twelve indexed BAMs and their called-barcode sets. Scientific preflight explicitly checks remote inputs again. No installations, containers or external downloads.

The controller runs on the office Mac. Each sequential sample task transmits the exact counter source and configuration through SSH stdin, runs on the LiSC login host in memory and returns compact JSON. This is bounded indexed Grm7 locus processing, not whole-BAM processing or Slurm scheduling. Remote BAMs, reference, barcodes and previous results remain untouched. Plot export uses the already available local Node 24, Playwright and Google Chrome in headless mode; no new browser is installed. All source files are standard Python/JavaScript and the run records source checksums.

Counts: corrected CB/UB, exclusively Grm7 GX, primary MAPQ255, rescued multimappers excluded (mm!=1), xf bits 2/4/32 excluded. Features have 1-based inclusive coordinates. Junctions require at least eight aligned bases on both sides. Features and compatible transcript upper bounds overlap; never sum them as gene totals. A conservative transcript count additionally requires unique compatibility, diagnostic features (>=20 bases in a unique exonic bin or a transcript-unique anchored junction) and anchored splicing. Shared, intronic and conflicting evidence remains explicit. These are RNA feature evidence counts, not long-read reconstruction, complete isoform abundance or protein abundance. Full gene counts from the original Cell Ranger matrix are a separate benchmark.

The analysis includes all twelve mice, superficial C2+C3 (C8 excluded), deep C1+C5, CA1/ProS total, inhibitory total and each original inhibitory cluster. No mouse, cluster or isoform is removed to improve an effect. Only descriptive per-animal displays and explicitly labeled support thresholds are used. All proposed biological interpretations require inspection of actual results.

Recovery version: transcript-junction compatibility compares coordinate values after JSON transport, with an end-to-end synthetic SAM/UMI regression test. Partial-CDS translation respects the first GTF phase, and partial coding transcripts remain labeled incomplete. The first run is retained but its transcript-compatibility outputs fail scientific QC; it is not evidence of absent isoforms.
