# Scientific plan: Grm1 alpha/beta in CA1 layers and inhibitory neurons

Objective: establish which Grm1 alpha/beta-associated RNA features are supported in each of twelve P60 mouse BAMs and whether descriptive WT/cKO patterns differ by frozen Seurat population. Primary populations are superficial CA1 C2+C3 (C8 excluded), deep C1+C5, all inhibitory nuclei, inhibitory C2 SST/O-LM-like and parent C6 SST. Original other clusters remain intact and tabulated. Mouse is the replicate; nuclei and lanes are not independent replicates.

Inputs: same twelve indexed mm10 BAMs and called-barcode sets as the completed Grm7 analysis, exact frozen CA1/ProS and inhibitory rosters, original all-gene count benchmarks, original mm10-2020-A GENCODE M23 GTF, indexed FASTA and reference manifest. Full original library counts are used as denominators. cKO_933 retains its original Cell Ranger 10.0 versus eleven 10.1 provenance; no sample exclusion to improve an effect.

Design: same primary alignment, tag, corrected CB/UB and anchored junction method as Grm7. Grm1's negative strand requires reverse-complement CDS and reverse exon ordering in transcript schematics. Verify alpha from the long 1199-aa tail (Grm1-201); verify beta from identical 906-aa CDS/proteins in Grm1-202 and -203. Count model-specific and alpha/beta-family diagnostic features, conservative uniquely compatible splice-supported UMIs and overlapping upper bounds separately. Also report family-exclusive junction and exon intervals with exact coordinates, per animal. Family evidence avoids confusing two UTR models of beta with two protein isoforms or assigning their shared reads arbitrarily.

Evidence contract: all12 samples must pass readable BAM/index, coordinate/header/sample and called-barcode checks; exact GTF checksum and protein translation must validate. Synthetic negative-strand, JSON transfer, deduplication, ambiguous beta, incompatible splice and tag-exclusion checks precede execution. Results must conserve gene UMIs across nonoverlapping clusters, record unsampled combinations separately, and reproduce source gene counts up to stated tag-filter differences. Display raw, per-1000-nuclei, full-library CPM and gene-relative counts with all denominators preserved. Color or layout changes cannot alter counts.

Recovery clarification: the GTF has six models, including three coding transcripts (201 alpha; 202/203 beta) and three noncoding transcripts (204/205/206). All six must compete for compatible reads. The initial three-model assertion stopped before counting and produced no biological results; it is superseded by the explicit six-model gate.

Claims: support for defined local RNA splice events is supported when observed; zero support is not proof of absence. Diagnostic exon-only signal does not establish mature transcript abundance. Conservative support is a lower-bound evidence count. WT/cKO plots are descriptive; no inferential isoform-switching claim, receptor protein level, physical-layer location, or functional synaptic change can be established from these reads alone. Descriptive support flag >=3 conservative UMIs in >=2 mice is not a hypothesis test.

Execution: reuse existing local Snakemake9.27 controller and read-only bounded LiSC locus extraction, with no installs, raw transfers or remote output trees. Separate new native run; user requested execution, so continue through Workbench readiness, immutable plan, native approval, monitoring, scientific review and atlas publication. Existing GitHub atlas receives additive page, source tables, vector/raster downloads, adjustable population, evidence, normalization, colors, labels and dot controls after review.
