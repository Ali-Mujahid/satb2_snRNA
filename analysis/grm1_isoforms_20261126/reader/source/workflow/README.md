# Grm1 alpha/beta RNA evidence in twelve mice

User-selected extension of the corrected Grm7 BAM/GTF evidence method. Keep the original Seurat CA1 superficial C2+C3, deep C1+C5, all eleven CA1 clusters and twenty inhibitory clusters unchanged. Inhibitory C2 and parent C6 are priority views. All six WT and six cKO mice are included, including recovered cKO_933. Output is descriptive per-mouse gene, transcript, protein-family, exon, junction, CDS and UTR UMI evidence; no new DESeq2 or isoform-switching hypothesis test.

Entry: Snakefile, JSON configfile with absolute roster, original_gene_counts, results_dir, bound_config, local_python, existing ssh_alias, SAMtools path and BAM/index/barcode paths. Existing local Snakemake 9.27 orchestrates sequential read-only SSH tasks on LiSC using Python 3.9 and SAMtools 1.22.1. The existing controller environment is reused without installation or a fully locked dependency closure. Local task Python 3.12, Node 24, Playwright and Chrome are already installed. Source Python uses standard library only. Local JSON/TSV/figures are saved under a fresh results_dir. No remote analysis files, BAM transfers, installations, cache changes, clustering or old-analysis modifications.

Reference is the original mm10-2020-A filtered GENCODE M23 GTF and FASTA. Grm1 is ENSMUSG00000019828, chr10 negative strand. Reverse-complement concatenated genomic CDS, select initial phase in transcript order, check complete translation without internal stops, and verify the 1199-aa alpha tail and identical 906-aa beta proteins from two UTR models. Grm1-201 encodes alpha; 202 and 203 encode the same beta protein. Retain all models but count beta protein-family evidence jointly, with no arbitrary splitting of shared beta reads.

All six GTF models are retained: the three coding models above and noncoding Grm1-204/-205/-206. Shared noncoding compatibility competes with alpha/beta assignments and is not treated as receptor protein evidence. The initial preflight-only attempt stopped on an overly restrictive three-model assertion before reference export or BAM counting; the recovery validates all six models explicitly.

Filters: primary MAPQ255, exclusive GX=Grm1, corrected CB/UB, mm!=1, xf bits 2/4/32 excluded. Deduplicate within each feature and population by (CB,UB). Junctions require >=8 contiguous matched bases on both sides. Diagnostic bins require >=20 aligned bases or a family/model-specific anchored junction. Conservative splice support requires compatible model/family exclusivity, diagnostic evidence and anchored splicing, excluding incompatible splice evidence. Exon-only diagnostic support can be pre-mRNA. Shared compatibility upper bounds overlap; feature counts are not additive gene counts. No count is claimed to reconstruct a full-length isoform or protein abundance.

Full-library denominators come from original_nCount_RNA, agreeing with representation_full_library_UMIs, not the rendered HVG-only nCount_RNA. Mouse is the independent unit. Missing mouse/population combinations are not biological zeros. Descriptive replicated-support flags (>=3 UMIs in >=2 mice) are explicitly not significance tests. Source-matrix comparison, negative-strand and synthetic read/UMI tests, UMI conservation and alpha/beta membership gates are required before accepting findings.

Runtime commands: Python 3.12 and SSH locally; /usr/bin/python3 and the configured SAMtools 1.22.1 remotely. The workflow expects the reference FASTA index and twelve BAM indexes already present. Figure export uses existing Chrome through Playwright; no download occurs during execution.
