# Cluster annotation evidence module

`annotate_clusters.py` runs only as a native workflow stage. It reads the completed 13 October result artifacts without changing them. It does not fit reference mapping, PCA, Harmony, graphs, UMAP, marker tests, or differential expression, and does not aggregate nucleus RNA counts.

```sh
python annotate_clusters.py --config MASTER.json --stage initial --outdir results/annotation_initial
python annotate_clusters.py --config MASTER.json --stage final --outdir results/annotation
```

The configuration contains `previous_run_root`, `study_root`, `tools` (`scanpy`, `seurat`), `branches` (`original_full`, `paired_original`, `paired_cellbender`), `populations` (`allcells`, `Excitatory`, `Inhibitory`, `CA1_ProS`), `main_resolution=0.4`, `representation=harmony`, and `cluster_filter_mode=shared_iterative_intersection`. Final stage also needs `initial_annotation_dir` and `marker_summary_dir`. Existing empty output directories are permitted; nonempty outputs are never overwritten. Completion receipts bind every input read before/after parsing and all delivered output hashes.

## Initial stage and shared analysis cohort

Every original Harmony cluster in both tools is reviewed and kept in the audit, including mixed/uncertain clusters and small clusters. Main analysis membership starts from the authoritative shared population roster. For All and EX, IDs belonging to an original cluster with fewer than 100 current nuclei in **either tool** are removed, group sizes are recounted, and the process repeats until stable. This produces identical main nucleus IDs in both tools and ensures each nonempty retained original cluster has at least 100 nuclei. Paired original and CellBender share the same iterative mask. CA1-ProS and IN retain all clusters without the 100-nucleus cutoff. Cells are retained in the full annotation audit with exclusion iteration/tool/group/reason; this source never deletes an input cell.

Original atomic cluster IDs are frozen. The same original cluster ID is carried by exact nucleus ID into the paired branches. Separately reviewed fresh paired clusters are secondary evidence, tagged `cluster_scope=fresh_branch`, and never define inference categories. Their optional All/EX display cutoff is reported separately from the shared main mask. The initial map uses already produced descriptive marker ranks and panel summaries: Scanpy panel fractions describe full cohorts; Seurat panel fractions and both rank-marker outputs describe their declared exploratory subsamples. Initial program calls are drafts pending WT-only/native corroboration.

Initial outputs include `cluster_annotations.tsv`, `nucleus_annotations.tsv.gz`, `annotation_retention.tsv`, `cluster_filter_exclusions.tsv.gz`, `cluster_filter_iterations.tsv`, `paired_frozen_membership_checks.tsv`, `atomic_population_index.tsv`, and `atomic_population_memberships.tsv.gz`. Index fields include `population_key,tool,branch,population,cluster_id,n_nuclei,membership_sha256,model_enabled`. Atomic membership rows are the exact kept IDs, with sample/condition. An empty registry atom hashes empty bytes; no ambiguous empty-set hash convention is used.

`gene_panel.tsv` / `plot_gene_panel.tsv` contain unique stable IDs from the supplied panel, explicit canonical review markers, and up to 20 previously ranked representative candidates per original cluster/tool/population. `gene_panel_selection_audit.tsv` records their roles and rank evidence. `panel_membership.tsv` retains repeated supplied group membership and both unmapped `AC129186.1` source rows. Stable IDs remain primary; symbols are display/evidence keys and are never collapsed into one count row.

## Final evidence and category definitions

R preparation first produces full chosen-source integer counts and gene/cluster/mouse expression sums for atomic clusters on the fixed masks. The summary stage computes full-cohort mean log1p-normalized expression/detection and WT-only equivalents, using actual full source-library denominators. Final annotation requires the completed arithmetic-only summary receipt, full `gene_cluster_summary.tsv`, and `gene_cluster_summary_WT.tsv`; nonempty atomic groups must retain the exact declared panel and nucleus denominators.

Reviewed identity remains hierarchical: majority broad/subclass atlas labels and their support/mixture fractions are shown alongside canonical and nonmatching marker signatures. Confidence categories describe which evidence agrees; they are **not calibrated probabilities**. Two detectable coarse genes can corroborate coarse expression, but do not prove a finer anatomical or morphological identity. Small IN/CA1 clusters receive explicit rare-group uncertainty and remain in the audit/model roster. Nonmatching glial/immune signatures within a neuronal reference mask are flagged; this does not diagnose doublets or ambient RNA.

Layer-associated program calls use **original-full WT-only** mean-log1p gene expression, standardized per gene across the original tool/population atomic clusters and averaged with equal gene weights over the supplied VEH programs. Satb2 is explicitly excluded from layer program definitions. A descriptive dominance flag requires a program-score gap of at least 0.5, a leading score of at least 0.3, and at least three program genes detected in 10% of the WT cluster; sparse WT evidence (<20 nuclei or <3 represented WT mice) remains unresolved. These operational flags are fixed, transparent evidence rules, not validated layer classifiers. Mixed/weak/conflicting programs remain explicit. IN workbook programs similarly describe expression evidence; terms such as basket, O-LM, border, and cholinergic are not assigned as proven morphology or neurotransmitter identity from a workbook heading.

The final original map can refine reviewed labels/programs **before** category pseudobulk is defined, while atomic IDs/masks stay unchanged. It is carried unchanged into both paired branches so altered cKO expression or denoising does not reassign layer membership. Full paired marker evidence is retained as sensitivity/corroboration, without redefining the WT-based category map. Every physical layer field remains `UNDETERMINED`; the source mask includes CA1-ProS reference candidates and cannot establish physical CA1-only membership or CA1 anatomy.

Final outputs add `full_cohort_marker_corroboration.tsv`, `annotation_program_scores_WT.tsv`, `label_refinement_audit.tsv`, `category_definition.tsv`, and `category_memberships.tsv.gz`. Category definitions have `tool,branch,population,category_family,label,member_cluster_ids` (JSON), `source_branch=original_full`, assignment basis, nucleus count and membership hash. They are disjoint atomic cluster unions within each family; all retained atoms, including unresolved/conflicting categories, are represented. Membership fields include tool/branch/population/category family/label/nucleus ID/sample/condition/source cluster. R finalization must verify these are exact unions of the declared native atomic arrays before modeling.

Annotation confidence is separate from model eligibility. The revised IN model may use all available nuclei in any nonempty positive-library mouse/cluster under the separately declared animal-replication guard; a one-nucleus mouse contribution never automatically establishes marker identity. Other populations retain their separate >=20-nucleus mouse/model rules. This source reports coverage rather than declaring genotype significance or a biological truth label.
