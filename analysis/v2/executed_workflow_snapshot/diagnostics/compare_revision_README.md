`compare_revision.py --config MASTER.json --outdir results/comparison` is the native final produced-artifact comparison rule. It performs no fits, raw-nucleus aggregation, graph construction, or source updates. It permits an existing empty output directory and refuses nonempty output content.

It requires completed finalized population, DESeq2, annotation_final, marker-summary, figure and CA1 diagnostic producers; the independent count-validation gate must be literal PASS with exact all-branch/final-population coverage. It binds consumed files to producer hashes where supplied, records actual hashes before/after parsing, verifies membership hashes and the all12 WT/cKO map, and preserves untested/missing result availability. Missing required PRIMARY or original core sensitivity audits fail completion. Only genuine unrequested fine sensitivity endpoints can remain absent.

Shared tool totals must contain identical nucleus IDs and exact all-gene/all12 integer arrays. Their effect agreement uses the **same DESeq2 implementation**, so it validates count/population/result consistency rather than independently implemented statistics. Fine crosswalks use Hungarian maximum overlap with reciprocal fractions>=0.5 and>=20 common nuclei; all weak/unmatched assignments are disclosed. Effect correlations and same-sign/FDR overlap use stable IDs and separately disclose common effect/P/FDR availability; a missing FDR is never classified as a nonsignificant result in the comparison denominator.

Paired original/CellBender comparisons require identical semantic population identities, exact nucleus memberships, and identical frozen primary gene universes. Count correction sensitivity is distinct from full-original cohort attrition. Endpoint guards bind poscounts normalization, signed-Wald cKO/WT contrast, independent mouse units, count branch, IN minimum1/other minimum20 nuclei per mouse,>=3 mice/genotype,>=2 residual df, no automatic replacement and declared independent filtering policies. All IN nuclei are aggregated; nonempty positive-library mouse groups are included under the model guard, with low-nucleus coverage exploratory. Marker identity confidence remains separate from model eligibility.

The native seven-field DE exports are exactly `gene,baseMean,log2FoldChange,lfcSE,stat,pvalue,padj`; the comparator checks exact row correspondence/numeric values to stable-ID audits, symbol-missing policy, audit FDR/P availability counts and captured warning counts. Source gene IDs are never collapsed by display symbols. Ancillary comparison/reliability tables add audit fields; the primary result exports remain seven columns.

`CORE_WT_cKO_RELIABILITY_ALL_GENES.tsv.gz` covers original-full core totals only. The stringent flag requires FDR<0.05 and a common nonzero effect direction in original-full/paired-original/paired-CellBender PRIMARY results, both original-full known-partition and main-partition effects estimable with the same sign, and all12 requested/tested leave-one-mouse-out effects estimable with the same sign. It reports LOO minimum/maximum effects and P/FDR availability separately. Partition/LOO significance is not invented or required beyond the explicitly documented flag. Fine populations receive PRIMARY only and cannot inherit the missing core sensitivity coverage. BH is within each endpoint; overlapping exploratory population definitions have no global correction here.

`LABEL_RELIABILITY_REVIEW.tsv` requires majority/high support and representative specificity/mouse evidence for finer labels, retains mixed/conflicting/rare/weak cases, and never validates physical layers. Two coarse canonical genes cannot certify a finer subclass. Source original-full representative evidence is explicitly carried to paired frozen populations; fresh secondary labels cannot inherit unrelated marker numbers. Effect tables disclose fine-label/overlap/low-coverage interpretation guards. Layer/IN program categories remain expression-associated WT-defined programs, not proven anatomy/morphology.

The final report links the native figure book index and retains actual PCA/graph/fixed-runner iteration/Harmony convergence diagnostic tables. Fixed graph/runner controls isolate iteration effects; original source graph comparisons also include upstream latent-space and graph-conversion differences. A graph swap is not labeled a pure backend causal contrast. Primary inference memberships remain frozen and are not replaced by diagnostic controls.

`COMPLETE.json` is written last, with actual input/output/source/config hashes and explicit review-required status. It records fitting/aggregation=false, statistical implementation independence=false, physical layer validation=false, and no automatic biological consistency verdict. Source syntax and four synthetic produced-table checks are available in `test_compare_revision.py`; they do not read study matrices or run scientific models.
