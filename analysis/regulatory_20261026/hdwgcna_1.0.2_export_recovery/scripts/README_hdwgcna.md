# hdWGCNA implementation and output contract

This is an additive workflow for the frozen Seurat populations. At drafting, only syntax and pure policy tests were run. No scientific fit or figure was generated by the code author. Execution belongs to the existing approval-bound Snakemake controller and its immutable configuration.

The upstream target is hdWGCNA **0.4.12**, commit **e3344d1f7bbac4264adf94f7aa31e0802fa8282d**. Dependencies are installed separately; this script never installs software or accesses online enrichment services.

## Invocation

The Snakemake rule should invoke the managed R environment with:

```sh
/usr/local/bin/Rscript source/scripts/run_hdwgcna.R \
  --config /absolute/path/config/hdwgcna.v1.json \
  --input-dir /absolute/path/prepared/lineages \
  --outdir /absolute/path/new_run/results/hdwgcna
```

`--config` contains a top-level `hdwgcna` object. Its `execute` value must be `true` in the approval-bound configuration. The script does not implement a separate user approval mechanism. It refuses a different code/input/config/package fingerprint in an existing output directory. A verified completed branch is skipped; a corrupt completed branch is preserved and rejected. An unfinished branch may resume only with its matching immutable identity. No previous analysis directory should be used as `--outdir`.

## Inputs

For each `CA1` and `IN` directory, `counts.mtx.gz` is integer raw UMIs, genes by nuclei; `genes.tsv` and `cells.tsv` are in exact matrix row/column order. H5AD is optional and not used.

- Genes: `feature_id`, `gene_symbol`, `gene_ids` (semicolon-joined stable IDs where symbols were collapsed), `symbol_missing`, plus mapping audit columns. Duplicate symbols were collapsed in input preparation, not in this script. Reversible `analysis_key` values replace Seurat-disallowed `_`/`|` characters and resolve resulting collisions; exported symbols and ID lists remain original.
- Cells: `nucleus_id` (unique column key), `barcode`, `sample_id`, `condition`, `endpoint`, `library_umi_full_genes`; `lane` and `sequencing_partition` support sensitivity analysis. Exact endpoints are `CA1_Deep`, `CA1_Superficial`, `IN_C1`, `IN_C6`, `IN_C8`.
- Normalize each original nucleus to `log1p(10000 * counts / library_umi_full_genes)`. The denominator includes every original measured feature. The same denominator is summed across each metacell's original constituent nuclei. Missing-symbol fallback genes remain in counts and the denominator but are excluded from discovery gene eligibility.

## Prespecified analysis

Separate genotype-blind pooled networks are primary: CA1 combines DL+SL, and IN combines C1+C6+C8. Genes are eligible if detected in at least 5% of nuclei in any corresponding endpoint. This is a full measured-RNA background, not an HVG-only or DEG-only universe. WGCNA's native good-gene check subsequently removes unusable variance/missingness genes, and the exact final background is exported. Co-expression can reflect endpoint identity or technical variation; it is not direct regulation.

HVGs (2000) and PCA (30 PCs) define metacell neighbors only. Every metacell stays within mouse × endpoint; membership checks explicitly verify genotype too. CA1 uses k25, max_shared10, min_cells50, target50 per group. IN uses k10, max_shared3, min_cells20, target25. Native metacell failures and underrepresented strata are recorded, not silently pooled. The 13-nucleus C8/cKO933 group is below the discovery threshold; its nuclei are still scored in the fixed module eigengene projection. Metacells overlap and are not independent genotype replicates.

The network uses signed bicor, maxPOutliers0.05, pearsonFallback='individual', and maxBlockSize3000 (hard upper limit4000). Powers1–10 and12–30 by2 are tested. The first power with fit≥0.8, negative slope and mean connectivity≥5 is selected. These are explicit operational validity criteria, not universal biological constants. No power meeting the gate means diagnostics and a stopped status, with no automatic fitted network. `exploratory_power` defaults null; only an explicit approval-bound tested value permits an exploratory poor-topology fit, which is labeled accordingly.

TOMs are computed within bounded blocks but not saved, avoiding large persistent files. The thin scientific state contains the native network object, block dendrograms, module assignments, metacell expression and eigengenes. Top-hub RNA correlation edges are exported; these are not full TOM edges, physical binding or TF-target interactions. A source quirk in hdWGCNA0.4.12 records a nonexistent TOM path when saving is disabled; the script clears that pointer. Another wrapper quirk mishandles exactly one failed metacell group, so official `MetacellsByGroups` is called per stratum and failed strata are recorded before merging successful native outputs.

After **both** primary network attempts, WT/cKO consensus is attempted only with ≥30 metacells and ≥4 mice having ≥2 metacells each per genotype. Native `SetMultiExpr` and `TestSoftPowersConsensus` align common good genes and test the two sets separately. Each must pass the same topology rule; native `ConstructNetwork(consensus=TRUE)` accepts the ordered power vector. Consensus is secondary and is not a genotype-specific differential network test. All consensus statuses and pooled/consensus gene-overlap counts are retained.

Raw PC1 module eigengenes are computed on **all original nuclei**, oriented by the native implementation to positive correlation with mean module RNA. Mouse and genotype are not regressed out or removed with Harmony. Grey genes remain explicit unassigned genes and are not treated as a scored biological module. Native `ModuleConnectivity(sparse=FALSE)` is necessary: its sparse=TRUE shortcut uses Pearson correlation despite a requested bicor function. Native bicor kME is used here, without reassigning negative-kME genes. Hub genes are RNA co-expression hubs, not verified regulators.

## Mouse-level inference and limitations

Scores are summarized once per independent mouse × endpoint. Separate continuous linear models (`mean_PC1 ~ condition`) estimate cKO−WT differences with confidence intervals. They are **module associations**, never DEGs, and no DESeq2/edgeR fit is run. At the output root, BH adjustment covers all tested CA1+IN module × endpoint associations together, separately for pooled versus consensus and primary versus sensitivity families. Branch `effects.tsv` is an unadjusted alias; use the output-root adjusted table for final inference.

Genotype partially confounds technical partition. Primary models do not establish an effect independent of all technical factors. An exploratory same-partition sensitivity uses the exact prepared metadata value (`sequencing_partition`='23HJT3LT4_lanes6_7' and/or explicit lane6/7 encodings). Missing coverage is reported as insufficient, not guessed. The expected same-partition subset is6WT/3cKO, and the actual sample counts are exported. Leave-one-mouse-out effect direction and a stratified independent-mouse bootstrap are sensitivity summaries, not additional independent replicates.

Fixed-module connectivity stability uses averages of the fixed nuclear PC1 scores over metacell members, recomputes gene-to-fixed-score bicor after removing each mouse, then reports correlation of full versus reduced kME vectors and top10 hub retention. This is explicitly **not formal WGCNA modulePreservation**, not de novo network refitting, and not evidence that a module is preserved between genotypes.

## Output schema

Files below appear under `<outdir>/{CA1,IN}/{pooled,consensus}/` for fitted branches. Status/diagnostics can exist without fitted results. The `analysis_key`/native `gene_name` is reversible through `network_genes.tsv`; scientific gene display uses `gene_symbol`.

| File | Essential columns / content |
| --- | --- |
| `module_membership.tsv` (`modules.tsv` alias) | gene_name, module, color, per-module kME columns, kME for assigned module, gene_symbol, gene_ids, assigned; grey retained |
| `network_genes.tsv` | all input feature mapping, endpoint detection fractions, eligible, excluded_missing_symbol, retained_after_goodGenes; use **retained_after_goodGenes** for actual fitted gene background |
| `network_gene_selection.tsv` | primary detection/eligibility selection before goodGenes |
| `hub_genes.tsv` (`top_hubs.tsv` alias) | membership columns + hub_rank; top20 per assigned module |
| `all_gene_hub_ranks.tsv` | every assigned finite-kME gene with within-module rank |
| `module_eigengenes_mouse.tsv` (`mouse_endpoint_eigengenes.tsv` alias) | sample_id, sample alias, condition, endpoint, module, n_nuclei, eigengene_mean, value alias, module_RNA_mean, available lane/partition |
| `nucleus_eigengenes.tsv.gz` | original per-nucleus metadata plus a wide column per non-grey raw PC1 module |
| `effects.tsv` (`module_genotype_associations_unadjusted.tsv` alias) | lineage, network, endpoint, module, n_WT, n_cKO, effect_cKO_minus_WT, SE, statistic, pvalue, CI_low, CI_high, model_status; unadjusted |
| `module_genotype_same_partition_unadjusted.tsv` | same continuous-model columns plus named sensitivity partition |
| `module_genotype_leave_one_mouse_out.tsv` | same model columns + omitted_mouse |
| `module_genotype_mouse_bootstrap.tsv` | mouse bootstrap CI, fraction_positive, resampling unit; fixed module scores |
| `fixed_module_connectivity_stability.tsv` | module, omitted_mouse, n_metacells_remaining, fixed_kME_correlation, top10_hub_fraction_retained, explicit method, formal_module_preservation=FALSE |
| `network_edges.tsv` (`top_hub_coexpression_edges.tsv` alias) | module, gene1, gene2, bicor, edge_type; bounded top-hub subset, not a complete adjacency matrix |
| `metacell_coverage.tsv` | source nuclei, resulting metacells, discovery status by mouse × endpoint |
| `metacell_membership.tsv.gz` | metacell_id, nucleus_id, sample_id, endpoint, condition |
| `metacell_metadata.tsv` | native metacell metadata and verified full-library denominator |
| `soft_power_diagnostics.tsv`, `selected_power.json` | complete tested powers, fit, slope, connectivity and explicit selected/gate status |
| `eigengene_orientation.tsv` | module correlation with mean RNA, harmonized=FALSE |
| `status.json`, `failure.json` if applicable | performed/not-performed validity status and limits |
| `analysis_state.rds` | thin recoverable state, native network/dendrograms, metacells, gene/module tables, raw MEs; excludes full original nuclei count duplication |
| `run_identity.json`, `completed.json`, `provenance.json` | immutable fingerprint, checked output hashes, parameters/input/source identity |

Output-root adjusted tables are `pooled_module_genotype_associations.tsv`, `pooled_module_genotype_same_partition.tsv`, and corresponding conditional `consensus_*` files. Each includes `padj` and the exact `fdr_family`. Root `sessionInfo.txt`, `run_parameters.json` and `workflow_status.json` record the environment and branch outcome.

Figures have PDF, SVG and PNG variants: metacell coverage, all soft-power diagnostics, each block dendrogram, mouse ME heatmap, module RNA dotplot, top-hub panels and mouse-level association confidence intervals. Raw tables accompany display z-scores. No synthetic layout enters inference. Before the first actual PDF-authoring workflow execution, the orchestrator must follow the PDF skill's operation marker/verification requirements; draft syntax testing creates no PDFs.
