# Regulatory programs, 26 October 2026

These are additive immutable scientific workflow snapshots for the frozen Seurat CA1 deep-associated and superficial-associated expression programs and inhibitory clusters1/6/8, with six WT and six cKO mice. Existing nuclei annotations, original DESeq2 gene fits and strict DEG-only ligand–receptor results are preserved.

- `hdwgcna_1.0.1/`: separate pooled CA1 and inhibitory signed-bicor networks, topology-gated optional WT/cKO consensus, original-nucleus PC1 projection, mouse-level associations/stability, GO enrichment and matched original-DESeq2 overlaps.
- `hdwgcna_1.0.2_export_recovery/`: verifies and copies the completed 1.0.1 prepared/network files without refitting, recovers enrichment graphics and final packaging, and preserves the bound original configuration and copy inventory. Both available components have now completed successfully.
- `collectri_1.0.0/`: native decoupler2.3.0 mouse-mapped CollecTRI ULM, full eligible RNA background and original size factors, separate continuous independent-mouse score associations, same-partition/LOO/bootstrap and SATB2 self-target sensitivity. Original Wald-statistic target enrichment is supplementary.
- `pySCENIC_REFERENCE_STATUS.md`: full motif-supported regulon inference is blocked on unavailable matching mouse cisTarget references. The isolated runtime is prepared, but no motif-supported regulons or AUCell scores are claimed.

`EXECUTED_CONFIG.json` preserves the exact original local paths and source hashes for provenance. To rerun elsewhere, acquire the hash-matching raw matrices/axes, original fit audits and resource files, install the recorded software in isolated environments, create a new configuration with the relocated inputs and fresh output root, and review/register a new immutable native workflow plan. Never point a new fit at a previous analysis directory. The existing controller/base R closure is not fully lockfile-backed; that reproducibility limit is explicit in the runtime contracts.

Installed software libraries and the original full H5AD remain external dependencies. The completed release archive contains selected raw MTX/genes/cells, recoverable RDS states, all native tables and figures, executed source/configuration and validation receipts. The online and standalone HTML explorers use only precomputed saved results; display controls do not refit statistics or alter native units.

The historical hdWGCNA-only plan predates the full TF method selection. `TF_AND_REGULON_PLAN.md` records the subsequent selection and actual branch scope. The strict communication analysis still requires original significant DEGs at both exact endpoints; regulatory/coexpression methods require a full eligible background and are separate from that restriction.

All associations remain exploratory because genotype partly confounds technical partition. IN_C8 retains mixed molecular identity. RNA coexpression and curated target-set activity do not demonstrate direct binding, causal regulation, physical communication or anatomical laminar position.
