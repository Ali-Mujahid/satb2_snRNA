Each test uses the unambiguous gene symbols with a finite DESeq2 adjusted P in that population. The one-sided hypergeometric test asks whether the overlap exceeds chance. Benjamini–Hochberg correction covers all 21 fitted populations. Up and down refer to cKO relative to WT.

Data and methods

The superficial model excludes CA1 C8 (CA1–prosubiculum). Both CA1 groups and the original inhibitory clusters use the saved mouse-level DESeq2 contrast, cKO versus WT. C6 refers to the parent SST cluster. IN C18 lacked an eligible fit. A strict pair requires a pooled LIANA candidate and an adjusted P below 0.05 for each component in its matching source or target. Only IN C1 and C6 contributed strict pairs. Molecular direction follows the LIANA resource.

Connectome-seq

The study measured barcode-paired connections from pons to cerebellum. We compared its 30 Purkinje-cell cluster markers with each local DEG list. Your libraries contain nuclear RNA without paired synaptic barcodes. This comparison tests gene-set overlap across circuits. The authors used engineered neurexin and neuroligin proteins to label synaptic partners.

SynDive

CA1 stratum protein log₂ fold changes come from Supplementary Data 2. SO, SP, SR and SLM denote oriens, pyramidale, radiatum and lacunosum-moleculare. For sorted synaptosomes, each stratum is compared with the remaining strata. The tissue comparison uses mean log₂ intensity across all four strata. A shared stratum can contain proteins from different cells or synapses. Superficial and deep pyramidal somata both lie in SP.
