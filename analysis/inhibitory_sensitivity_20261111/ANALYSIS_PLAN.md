# Independent Seurat inhibitory pseudobulk audit

Objective: verify historical C1/C2/C6/C7 results and sequencing-group sensitivity without changing previous outputs. Source is the frozen 12-mouse Seurat original_full inhibitory pseudobulk package; each biological mouse is one experimental unit. Frozen 20 inhibitory clusters and total remain separate, no new annotation or clustering. Mouse-level UMI matrices are used with fixed original primary gene universe, discarding genes all-zero after subset. Contrast cKO/WT. DESeq2 poscounts, Wald, parametric, no automatic count replacement, BH within each endpoint, independent filtering on, alpha .05; results and size factors saved, separate endpoint families. Current DESeq2 version is recorded; reproduction compared with historical stable-ID outputs. No edgeR.

Models: original inclusive mouse threshold >=1 nucleus; same main recorded partition (6 WT/3 cKO where eligible); known-partition additive group-adjusted (unverified 933 excluded); >=20-nucleus sensitivity; leave one mouse out for C1 and C6, >=3 each condition and >=2 residual df. No batch adjusted model when rank deficient or replication inadequate, explicitly mark untested. Sequencing group is a pre-existing metadata label, not confirmed independent of manifests; no inference from label alone that batch is causal. Fixed historical gene universe makes model comparison consistent, not a refilter to discover more DEGs. Inhibitory total is composition-sensitive and descriptive. Each model's missing results remain NA; gene symbols not unique and stable IDs retained in audit. Do not manufacture 20-nucleus boss results or statistical equivalence/simulation results without source scripts. Output plots of sample-normalized candidate expression and model effect comparisons; independent mice, no p-hacking. Prior results and fits untouched.
