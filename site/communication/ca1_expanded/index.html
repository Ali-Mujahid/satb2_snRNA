Population, counts and DE availability

For each group, a pseudobulk count matrix sums raw integer gene counts by biological mouse. It is not a per-nucleus matrix; the sample columns, included nuclei, QC and model eligibility are documented with the scientific outputs. Count and DE files are provided only where the reviewed data package declares them.

CA1 C10 is an exploratory low-coverage group; review per-mouse eligibility before interpreting it. CA1 C11 has 99 nuclei and an identity-conflict flag in the previous analysis and is not an eligible original layer-specific DE endpoint. Its metadata and any available counts remain separate; do not interpret missing DE or interactions as zero.

Data and provenance

Whole-CA1 and CA1 layer groups overlap with constituent clusters and must not be interpreted as independent populations. A displayed filter does not refit DESeq2 or LIANA. Results are condition-specific descriptive rankings, not interaction-level WT–cKO hypothesis tests.
