Source and interpretation

FDR is adjusted within each saved fit. The default |log2FC| cutoff is zero, preserving the original DEG counts. Moving the display cutoffs changes the displayed gene selection; it does not refit DESeq2 or test differences between layers. Missing adjusted P values remain unavailable. Points outside the chosen axes are omitted and counted, rather than placed at the plot edges. Zero P values use a numerical display floor of 10⁻³⁰⁰. Labels and downloads use exact stable gene IDs.

These molecular groups are not a direct measurement of anatomical location. The existing full-cohort analysis and its technical-group limitations are preserved. No cell classification, model, or LR analysis is changed by these controls.
