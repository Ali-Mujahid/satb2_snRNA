# Hosted atlas engineering

This is the v3 web adaptation of the preserved offline explorer. It includes 889 marker genes: the original 878 plus eleven descriptive summaries calculated from existing full-gene integer-count objects against the exact frozen native atomic memberships. Original marker values, nulls, endpoint identities and fit membership rules are preserved. The marker extension does aggregate those eleven genes; it does not refit QC, clusters, embeddings, annotations or differential-expression models. Opening the webpage changes views and local display state only.

Interactive gzip binary shards use same-origin project-relative paths. Exact original source-download payloads stay pinned to `https://raw.githubusercontent.com/Ali-Mujahid/satb2_snRNA/atlas-v2.1.0/data_downloads/`. Publishing v3 must not rewrite that historical data pin or move the v2.1 tag. The loader verifies compressed bytes against their SHA256, decompresses explicit gzip magic with a browser-native stream or bundled fflate, verifies the decoded JSON payload hash and parses JSON. Remote JavaScript is not evaluated. HTTPS/WebCrypto is required for the hosted loader. The decoded cache is bounded to six entries and two simultaneous decodes.

The source-data manifest, DE catalog and mouse catalog remain classic local JavaScript globals. The v3 base manifest registers eleven additional genes, the ordered 75-gene preset and updated marker shard hashes. The native source fingerprint remains the original count/membership fingerprint, with separate marker-extension provenance. The original DE and full-gene mouse catalogs and their source payloads remain unchanged. `published_downloads.js` holds native/PDF/archive release links and integrity metadata; the publisher fills archive SHA256/size fields after packaging. Native download and review-document links point to retained versioned assets, rather than an omitted multi-GB offline folder.

The portable v3 delivery uses `SATB2_atlas_v3_runtime.zip` plus `SATB2_atlas_v3_saved_results.zip` from release `atlas-v3.0.0`. Both are ordinary ZIPs with the common root `offline_dashboard_v3/`; extract both into the same parent folder and open its `index.html`. The classic offline loader needs no network or local server. Historical v2/v2.1 deliveries and legacy assets remain available.

The **Screenshot · all 75 genes** preset preserves image order and fifteen five-gene blocks, switches to 90 genes per page and descending cluster rows. Screenshot blocks are presentation groups, not atlas cluster identities. Automatic cluster-pattern or focus-cluster order uses the selected reference tool to define one shared gene-column sequence for both tools. The criterion is mean log1p expression minus the nucleus-weighted mean of other retained displayed rows, with detection contrast breaking ties. It is descriptive display ordering, not differential expression or a new validated representative-marker selection. Flat, zero, tied and incomplete patterns remain unassigned. Manual pasted orders, individual moves and separate per-tool custom row orders are available; exports record the displayed ordering. See [the ordering guide](https://github.com/Ali-Mujahid/satb2_snRNA/blob/main/docs/marker_preset_v3.md).

The hosted page downloads public static data; local labels/settings are not uploaded. UMAP-only genotype/programme filters and marker ordering do not alter the saved inference population. Novel exclusions/unions without an exact saved membership show NO MATCHING FIT. Missing or unsupported size factors remain NA. The extension retains the original contract that cKO marker z-scores are unavailable; use mean expression for that scope.

Engineering receipts and the earlier browser acceptance report are maintained separately from v3 checks. The eleven-gene extension's provenance and validation tables are in `analysis/dashboard/v3_marker_extension/` in the repository; all 64,548 new integer sums match the existing 489 atomic arrays. A VM test is not a browser witness. V3 browser acceptance must be recorded after testing the deployed v3 page.

Hosted reader patch atlas-v3.0.1 versions compressed shard requests by their expected SHA256. Bare descriptor paths, pinned exact-download locations, omitted credentials, redirect rejection and compressed/decoded integrity checks remain enforced. Offline v3.0.0 archives are unchanged.
