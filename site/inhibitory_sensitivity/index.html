Mouse-level candidate expression

Each point represents one mouse. Values are counts normalized using that model’s own DESeq2 size factors; the restricted model is refitted and excludes the three mice. Full and restricted panels therefore need not use identical normalization. Group shapes: ● main recorded group, ▲ second group, ■ unverified.

Candidate mouse plots are available for C1, C6 and C7. Points use horizontal spacing only for readability. All nuclei in each mouse’s original cluster are used in the primary fits.

Methods and downloads

Frozen Seurat original-full populations and original integer UMI pseudobulks; DESeq2 Wald test, poscounts size factors, original frozen gene universe, cKO versus WT, BH within each endpoint. Rare or insufficiently represented clusters remain not tested. Counts for different cell populations overlap and are not independent. No new clustering or labels.
