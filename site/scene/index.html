SCENE projects nuclei and genes into a shared embedding. The map shows nuclei coloured by the original Seurat labels and can optionally mark one gene position; mixed nuclei remain mixed. Marker plots show measured counts, not SCENE distances. This is exploratory, not an anatomical map or WT–cKO test.

Controls

Stars mark a saved gene coordinate in the 2D joint UMAP, not gene expression or anatomical position. This projection can distort distances.

Marker appearance

The 30-marker preset uses three candidates per cluster C1–C10. Groups describe selection, not exclusivity. Genes outside the saved panel cannot be plotted here.

Cluster selection applies to the cluster map and cluster marker plots. Layer summaries are fixed saved groups and are not recomputed when clusters are hidden.

Marker expression heatmap

Same marker order, row order, cell dimensions and color scale as the dotplot. Dot size encodes detection only in the dotplot.

Data and interpretation

Gene-wise z-scores are calculated across all original cluster rows, not recomputed when rows are hidden. Layer summaries use C1+C5 and C2+C3+C8; C4/C6/C7/C9/C10 and conflicted nuclei are not forced into either group. Colors and labels are display settings only.

SCENE used 2,518 selected genes, 16 dimensions, a ZIP model and mouse batch adjustment; it can suppress genotype-related variation. The gene points in the original 2D projection fell away from nuclei, so marker–cluster proximity should not be inferred from the display. No new DE test is performed.
