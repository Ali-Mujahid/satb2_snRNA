Interpretation and limitations

All comparisons use the existing Seurat original-full pseudobulk fits. Superficial-associated = C2+C3+C8; deep-associated = C1+C5; the total includes C1–C11, including mixed and identity-conflicted nuclei. Overlap results exclude the exploratory C10 and untested C11 standalone fits. The groups are nested and use the same mice; FDR adjustment is separate for each fit. Sequencing partition is partly confounded with genotype.

The common-tested comparison restricts the universe to 3,806 genes with available adjusted P values in all 12 primary fits. It is a sensitivity view, not an independent validation. Missing adjusted P values are unavailable, not evidence of no effect.
