What the completed analyses support

The primary hdWGCNA networks contain 10 CA1 modules and 5 inhibitory modules. The separate curated TF analysis finds 23 mouse-level associations at FDR < 0.05 across 2,768 tested population–TF combinations. None passes FDR in the smaller matched sequencing-partition sensitivity analysis, and SATB2 activity is not FDR-significant in any of the five populations, including its separate self-target sensitivity. These are exploratory molecular signatures.

Original gene DESeq2 results, DEG-only communication pairs, coexpression modules and TF scores answer different questions. Their effect sizes and FDR values are not interchangeable. Read the detailed findings and interpretation guide before selecting a biological mechanism. Motif-supported pySCENIC inference remains unavailable because matching mouse reference files could not be obtained.

Keep these measurements separate

hdWGCNA: coexpression modules, module eigengenes and hub membership summarize the fitted network. Module names and hub ranks do not establish direct regulation. Curated TF activity: activity inferred using a declared TF–target prior is separate from the TF’s own RNA expression. Self-target links can contribute to the score; see the separate SATB2 sensitivity. Some significant target signatures have little or no measured RNA from the named TF; a score alone does not establish its activity in these neurons. Motif-supported regulons: this label is reserved for outputs with explicit motif / cis-regulatory support.

Network colors show saved RNA-correlation signs or curated regulatory-prior signs. WT–cKO changes are reported in the saved genotype-effect tables. Native within-mouse gene-set FDR and mouse-level genotype-association FDR answer different questions.

Each mouse is an independent biological replicate. Display z-scores, genotype means, colors and graph layouts do not fit statistical tests. Saved genotype effects require their original eligible cohort. CA1 program labels describe molecular expression programs; anatomical layer position remains undetermined.

The existing nuclei atlas and corrected DEG-only ligand–receptor analysis retain their original sources and eligibility rules.
